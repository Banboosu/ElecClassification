## 1. 论文范围

本文以完成一篇结构完整、结论谨慎、实验可复现的学生论文或普通期刊论文为目标，不追求一次性
完成所有基础模型、迁移学习、生产回放和安全部署实验。

当前最稳妥的核心结论是：

> 在当前真实内部充电功率三分类任务中，预训练 MOMENT 表征配合 RBF-SVM 在 1%–10% 标签条件下
> 比从头训练 TCN 获得更高的 Macro-F1 和更低的跨随机种子波动；标签充足时，TCN 以更低训练成本
> 获得接近或更高的分类性能。

论文不声称：

- MOMENT 全面优于 TCN；
- 当前结果达到该领域最优；
- 单一离线指标可以直接推动线上模型替换；
- 模型已经能够执行无漏检的安全报警或早期预警；
- 现有结果证明所有优势都由预训练单独造成。

### M01 预训练归因简化消融

目的：判断低标签收益是否至少部分来自 MOMENT 预训练权重。

- [x] 条件 A：预训练 MOMENT-1-large，冻结 encoder，使用当前 RBF-SVM。
- [x] 条件 B：相同架构随机初始化，冻结 encoder，使用完全相同的 RBF-SVM。
- [x] 只运行 1%、5%、10% 标签比例和 seeds 42–46。
- [x] 两个条件使用相同样本 ID、预处理、池化方式、特征维度和 SVM 参数搜索范围。
- [x] 报告 Macro-F1 均值、标准差、逐 seed 配对差和 95% 区间。

结果：预训练相对随机初始化在 1%、5%、10% 标签下分别提高 28.60、22.58、22.01 个
Macro-F1 百分点，95% 配对区间为 [22.24, 34.97]、[20.89, 24.28]、[20.48, 23.53]
个百分点，15 个逐 seed 差值均为正。完整记录见
[M01 预训练归因简化消融](experiment_records/m01_pretraining_ablation_20260805.md)。

不要求增加时间打乱、有效秩、类内距离、密集标签比例或 AULC。若该实验暂时无法完成，论文把
“预训练提高标签效率”降级为“预训练 MOMENT + RBF-SVM 管线在低标签条件下优于当前 TCN”。

### M02 轻量错误分析

- [x] 为 TCN、完全微调 MOMENT 和低标签 MOMENT-SVM 保存逐样本预测及类别分数。
- [x] 汇总每类主要错误方向，重点报告电池异常漏检和高置信误报。
- [x] 绘制少量固定规则选出的典型错误曲线，不按视觉效果挑选样本。

结果：五随机种子共导出 25 个逐样本预测文件；完整标签 TCN、MOMENT 及 1%/5%/10%
MOMENT-SVM 均完成逐类别混淆、电池漏检与运行内前 10% 置信边际误报分析。有效长度固定分为
≤237、238–332、333–439、>439 四档，所有方案在最长档均表现偏弱。seed 42 按六条预声明
规则生成典型错误曲线；完整记录见
[M02 轻量错误分析](experiment_records/m02_error_analysis_20260805.md)。

可选：如果现有推理脚本很容易支持，只增加一个噪声条件或一个 50% 输入前缀条件。高斯噪声、
随机缺失、连续缺失、下采样、幅值漂移和多级前缀的完整网格不属于当前必做范围。

### M03 实验协议最终检查

- [x] 核对正式表格中的所有运行均使用固定 split manifest 和相同指标实现。

完整记录见 [M03 实验协议最终检查](experiment_records/m03_protocol_audit_20260805.md)。
