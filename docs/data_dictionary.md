# 数据字段与标签约定

## 字段

| 字段 | 当前用途 | 说明 |
|---|---|---|
| `charging_station_id` | 样本唯一 ID | 用于固定划分清单、预测追踪和实验产物关联。 |
| `InsertedColumn` | 分类标签 | 训练前转为字符串，再由 `LabelEncoder` 编码。 |
| `charging_powers_str` | 功率时间序列 | 逗号分隔的浮点数序列。 |

## 标签

当前业务映射（2026-10-29 用户确认纠正；不改变原始数字标签）：

| 标签 | 项目中的含义 | 是否进入当前三分类实验 |
|---|---|---|
| `0` | 正常 | 是 |
| `1` | 电池异常 | 是 |
| `2` | 充电器故障 | 是 |
| `5` | 无效或不完整记录 | 否 |

旧 README、代码注释及报告把标签 `1` 与 `2` 的业务含义写反；旧代码的相互一致不能证明
该业务解释正确。本次纠正依据是用户确认，尚未附数据提供方原始 codebook，不以曲线形态反推故障。
`LabelEncoder` 的数字类别顺序仍为 `[0,1,2]`：不修改 CSV、split、训练目标或保存的 score 列。
统一的新语义定义见 `src/tcn_moment/label_semantics.py`。

影响范围：三分类 Macro-F1、Accuracy 不因类别名称更正而改变；逐类表头和样例图例需对应更正。
电池 one-vs-rest 指标须使用标签 `1` 与 `score_1` 重算，旧 `battery_*`/`score_battery` 通常对应
标签 `2`，应解释为充电器故障指标。旧类别 `2` 专用二分类模型与报警阈值不能直接当电池模型使用。
详见 `docs/experiment_records/label_semantics_correction_20261029.md`。

用户已明确否定`legacy/ceshi.py`和`legacy/画曲线测试.py`；两者不得作为代码实现、标签字典、采样间隔、传感器量程或故障机理依据。旧数据字典对ceshi注释的引用撤回，归档副本只作追溯。最短18点是历史冻结实验的筛选参数，其独立业务来源尚未确认，不能据错误脚本换算成7.5分钟或称为专利/硬件规则；本次不更改原始数据与既有split。见 `docs/experiment_records/rejected_legacy_sources_audit_20261029.md`。

标签 `5` 的“无效或不完整记录”定义来自当前项目配置和既有 README；其数据也呈现明显的短序列
特征：11,435 条标签 5 中绝大多数短于 18 个时间点。标签 5 按内部既定数据处理规则不进入
0/1/2 三分类训练与主评估，其数量、长度和起始电压统计用于记录排除协议的一致性。
