这里的`charging_station_id`是样本唯一ID，**不是已经核实的充电设备ID**。没有找到设备、站点、时间或独立批次映射。现在不能可靠执行设备分组或时间外推，也不能从ID前缀/曲线相似性猜组。

## 最小补充材料

### 仅补旧样本元数据：可做回溯性分组/时间研究

提供一个UTF-8 CSV，以现有`charging_station_id`为唯一关联键，至少补充以下一种真实信息：

- **留设备研究**：`charger_id`，真实充电设备的稳定脱敏ID。同一设备的不同会话必须保持同一个ID。可选`site_id`和`battery_id`，并明确分别代表站点、充电设备还是电池/车辆，不能统称设备而不说明对象。
- **时间外推研究**：`session_start_utc`和最好同时提供的`session_end_utc`，ISO8601、明确时区。若不能提供绝对时间，可提供业务确认的可排序采集批次/相对时间，并说明单位与排序含义。只有文件修改时间或CSV行号不能代替采集时间。

模板：`configs/data_templates/external_metadata.csv`。模板只有表头，没有伪造示例数据；未提供的可选项可以留空。字段字典和脱敏说明可另附文本。

**补元数据本身不会创造一份从未见过的新test。**旧样本已用于此前随机split的训练、选择或评价；重新分组时必须重新划分并重新训练相关模型，隔离目标组，且明确这是回溯性研究，不能包装成全新外部确认。

### 真正新增采集：可准备新的锁定外部评价

另提供新采集批次的三列原始样本CSV（同现有格式），以及上述关联元数据/批次来源说明：

- 样本ID不得与旧数据重复；不能只是把旧记录换ID重新打包。
- 沿用业务确认的0/1/2标签定义及5排除规则，说明标注流程，不根据模型预测补标签。
- 提供真实批次来源和采集时间范围，确认未用于现有模型开发。若要声称留设备泛化，应能使用一致的脱敏设备ID检查新旧设备重叠。
- 在查看新test预测前固定主任务、比较方法（必须含TCN和强化统计参照）、指标、分组/时间边界、模型选择与训练预算，以及重叠/近重复检查规则。

不需要提供真实设备编号、车主身份、联系方式、精确站点位置或脱敏密钥。脱敏ID应在相关批次间保持一致，否则无法核查设备重叠。

## 收到材料后才执行的检查

1. 字段/类型、样本ID唯一性、与旧样本的关联覆盖率、缺失值及同一ID冲突。
2. 设备/批次数量及各类覆盖情况；无法支持留组评价时如实记录，不自动更换有利分组。
3. 时间有效性与会话跨分界情况；训练样本不能包含分界后的信息，必要时使用间隔或剔除跨界会话。
4. 样本ID、序列重复及设备重叠核验。只有内容相似性不能证明设备独立，内容不同也不能证明来源独立。
5. 冻结独立协议后再运行；旧模型如曾训练过拟留出的设备/样本，不能直接沿用来宣称留组效果。
