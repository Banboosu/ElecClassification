# 论文证据、MOMENT 优势方向与补实验台账

> 建立日期：2026-08-05  
> 对应初稿：[paper_draft_20260805.md](paper_draft_20260805.md)  
> 原则：先写可证伪假设，再跑实验；validation 用于选择，test 只做一次最终评价；正结果、负结果
> 和失败运行都记录。除非本表的证据门槛满足，不升级论文主张。

## 1. 当前最稳妥的论文定位

主线不是“MOMENT 全面优于 TCN”，而是：

> 在单一充电功率三分类数据集上，冻结 MOMENT 表征配合 RBF-SVM 在 1%–10% 标签条件下比从头
> 训练 TCN 具有更高的 Macro-F1 和更低的跨种子方差；标签增加后优势消失，完整标签条件下 TCN
> 以接近或更高效果获得显著更好的计算效率。MOMENT 的跨任务迁移具有边界。

这条主线已有直接结果支持，但“优势来自预训练”仍缺同架构随机初始化和强通用表征基线；
“可以泛化到真实部署”仍缺标签核验、设备/时间分组和外部数据。

## 3. 投稿前 P0 实验

### E01 标签、采集与数据治理核验

**目的。** 解决当前最大的非模型风险：类别名称和过滤规则只有项目约定，没有可审计的业务定义。

**需要数据提供者回答。**

1. 采集系统、传感器/计量来源、功率单位和采样间隔；变长序列的起止条件。
2. 标签 0/1/2 是由人工、维修工单、规则还是设备告警生成；判定时间是否晚于输入曲线。
3. 标签 5 的产生条件，是否可能包含真实故障，长度阈值 18 的业务依据。
4. 是否存在同一车辆、充电器、站点或会话的关联 ID；是否有可用时间戳。
5. 脱敏过程、伦理/隐私约束、可在论文中披露的数据统计和复现方式。

**产物。** `docs/label_and_acquisition_protocol.md`、字段级数据字典、签字/邮件确认记录摘要；
若能取得分组字段，生成去标识化 group/time manifest。

**判定。** 若无法确认 0/1/2 的业务含义，正文只能使用“类别 0/1/2”，不能使用“正常、充电器
故障、电池异常”；若无法确认标签 5，需增加“含/不含标签 5”敏感性分析或删去其业务解释。

**状态：** 等待外部信息。  
**资源：** 无 GPU；人工协调。  
**阻塞：** 数据提供者。

### E02 预训练归因消融：同架构、同分类器、同样本

**核心假设 H02。** 低标签收益来自 MOMENT 预训练权重，而不是 3.41 亿参数随机特征或 RBF-SVM
本身。

**方法。**

- 条件 A：预训练 MOMENT-1-large，冻结 encoder，当前 mask-aware pooling。
- 条件 B：相同配置但随机初始化 MOMENT-1-large，冻结 encoder。
- 条件 C：预训练 MOMENT，但在每条有效序列内确定性打乱时间顺序后提取特征，用于检验时间结构
  是否被利用；该条件只作机制分析，不替代 B。
- 三个条件使用相同 z-score、相同 1/5/10/20/40% 嵌套样本、相同 1,024 维池化、相同 RBF-SVM
  C 网格、相同五折训练内交叉验证和相同 seeds 42–46。
- validation/test 不参与 C 选择。先完成 seed 42 冒烟并核对数值有限，再跑五种子。

**主要指标。** Macro-F1、Balanced Accuracy、各类 F1、低标签学习曲线面积（E04 定义）和五种子
配对差；同时报告特征方差、有效秩和类间/类内距离，检查随机特征退化。

**预注册判定。** 只有当预训练条件相对随机初始化在低标签曲线面积上的 95% 配对区间下界大于
0，且至少在 1%、5%、10% 中两个比例的 Macro-F1 配对区间下界大于 0，才把论文表述升级为
“MOMENT 预训练提高标签效率”。否则只能写“预训练 MOMENT + RBF-SVM 组合优于当前 TCN”。

**状态：** 未实现。  
**优先级：** P0，证明 MOMENT 优势最关键的因果消融。  
**资源估计：** 中；5 次特征提取 + CPU SVM，预训练特征若可复用则只需新增 B/C。

### E03 强基线与分类器匹配

**核心假设 H03。** MOMENT 的低标签收益不仅相对一个从头训练 TCN 成立，也能与高效通用时序
分类/自监督表征方法竞争。

**最低必做基线。**

1. MiniROCKET 或 ROCKET + ridge/logistic classifier；
2. TS2Vec，在每个 seed 的训练 split 上进行无标签自监督训练，再用与 MOMENT 相同的 RBF-SVM；
3. TCN encoder 表征 + RBF-SVM，分类器和 C 网格与 MOMENT 相同；
4. MOMENT 表征 + 线性/RBF 两种分类器，用于拆开“表征”和“分类器”效应。

**可选增强。** InceptionTime、Hydra/MultiROCKET、另一个公开时序基础模型。选择前固定版本和
协议，禁止看 test 后追加只对 MOMENT 不利或有利的设置。

**公平性要求。**

- 相同比例/seed 使用相同样本 ID；所有无标签预训练只能读取该 seed 的训练 split。
- 对需要定长输入的方法，预注册“有效区间重采样长度 + 独立长度特征”方案，不能让 padding 0
  形成捷径；另做不含长度特征的敏感性分析。
- 给所有需要调参的下游分类器相同的训练内 CV 预算；test 只在配置冻结后读取。
- 同时报 Macro-F1、训练/推理成本和标签曲线，不只报单点最好值。

**预注册判定。** 若 MOMENT 在 1%–10% 的曲线面积和至少两个比例上超过所有强基线，才可使用
“相对通用时序表征仍有标签效率优势”。若 MiniROCKET/TS2Vec 相当或更好，论文改为“基础模型
与强轻量表征的条件化比较”，不得继续把 MOMENT 写成唯一优势方法。

**状态：** 未实现。  
**优先级：** P0，最可能的审稿意见。  
**资源估计：** 中至高，取决于 TS2Vec 训练；MiniROCKET 低成本，应先完成。

### E04 密集标签学习曲线、调参预算与标签节省量

**核心假设 H04。** MOMENT 的优势集中在一个可重复的低标签区间，并能转化为可解释的标注节省量。

**方法。**

- 在现有 1/5/10/20/40% 基础上至少增加 0.5%、2%、15% 和 30%；若算力允许，再加 60%、80%。
- 每个 seed 内保持严格嵌套；记录实际样本数和每类样本数。
- 为 TCN 预注册一个小网格，例如学习率、weight decay、dropout 各不超过 2–3 个值；MOMENT-SVM
  保持现有 9 个 C。报告每种方法总搜索次数和总计算时间，避免隐性调参预算不等。
- test 结果只在所有配置由训练/验证流程冻结后生成。

**主要指标。**

- 以 `log10(标注样本数)` 为横轴、Macro-F1 为纵轴的梯形积分面积（AULC）；
- 达到 75%、80%、85%、90% Macro-F1 所需的插值样本数及 bootstrap 区间；
- 跨 seed 的均值曲线、标准差和配对差；
- 各类别 F1 的学习曲线，检查整体收益是否由单一类别驱动。

**预注册判定。** 以 AULC 配对区间为主，不再逐点挑选最有利比例。只有当 MOMENT AULC 的区间
下界大于 0，且达到预定 Macro-F1 门槛所需标签明显更少，才使用“节省标注”的表述。

**状态：** 部分完成（已有 5 个比例 × 5 seeds）。  
**优先级：** P0。  
**资源估计：** 中；MOMENT 特征可复用，新增成本主要为 SVM 和 TCN。

### E05 三分类错误分析与输入鲁棒性

**核心假设 H05。** 预训练表征在低标签下不仅平均精度高，而且对现实输入退化更稳健。

**前置实现。** 通用三分类推理保存每条样本 ID、三个类别概率、预测、真值、有效长度和基础统计量。

**固定退化条件。** 对干净 test 的副本施加退化，不重新训练：

| 退化 | 建议级别 | 备注 |
|---|---|---|
| 高斯噪声 | 训练集有效点标准差的 1%、5%、10% | 只作用于有效点 |
| 随机缺失 | 10%、25%、40% | 所有模型共享相同 mask；明确基线补值规则 |
| 连续缺失 | 10%、25%、40% | 位置由样本 ID + seed 决定 |
| 下采样 | 2 倍、4 倍 | 再用预注册方法恢复输入长度 |
| 幅值漂移 | ×0.8、×1.2；加固定偏置 | 检验 raw TCN 的量程依赖 |
| 输入前缀 | 25%、50%、75% | 与 E07 共用实现，但三分类和安全指标分开 |

**比较对象。** 至少包含完整标签 TCN、完整微调 MOMENT、5%/10% TCN、5%/10% MOMENT-SVM 和
随机森林。主要指标为 Macro-F1 绝对值、相对干净条件保留率和 Battery FNR/FPR；禁止只报对
MOMENT 有利的 feature cosine。

**错误分析。** 按“多个模型共同错、仅 MOMENT 对、仅 TCN 对、高置信错误”分层绘制确定性样例；
按有效长度分箱报告 Macro-F1；比较错误样本的长度、均值、`diff_std` 和 `max_abs_diff`。

**判定。** 只有当 MOMENT 在预注册退化集合的平均性能保留率上领先，配对区间下界大于 0，才能
新增“输入退化鲁棒性”主张。否则保留负结果或混合结论。

**状态：** 未实现。  
**优先级：** P0（期刊通常要求错误分析/鲁棒性）。  
**资源估计：** 中；以复评为主，无需全量重训。

### E06 协议清理：全局标准化与 CNN FP32

**目的。** 排除当前主表中两个容易被质疑的协议不一致。

**E06a 训练集全局标准化。** 每个 seed 只用训练 split 的所有有效点计算均值/标准差，原样应用于
validation/test；与 raw、逐序列 z-score、逐序列 min-max 的 TCN 做五种子配对。保存 scaler
统计，不读取 padding 和测试信息。

**E06b CNN FP32。** 用最终代码、FP32、相同 seeds 和 split 重跑 CNN；若数值与现有 AMP 结果
差异大，以 FP32 结果替换论文主表，旧结果保留为诊断记录。

**判定。** 若全局标准化接近或超过 raw，论文将“幅值有效”改写为“逐序列归一化丢失跨样本尺度，
但训练集尺度校准足够”；若 raw 仍稳定领先，保留幅值信号假设，仍不称其为故障机理。

**状态：** 未完成。  
**优先级：** P0。  
**资源估计：** 低，约 10 个轻量 GPU 运行。

### E07 早期检测与安全错误人工复核

**目的。** 判断模型能否在完整曲线结束前识别电池异常，并核查现有错误是否来自标签或采集问题。

**方法。**

- 使用前 25%、50%、75% 和 100% 有效曲线；训练独立前缀模型与“完整模型直接推理前缀”分开报告。
- 每个前缀的阈值只在对应 validation 前缀上按 max-F2 和 95%/99% Recall 选择，再应用于 test。
- 比较完整标签 TCN、完全微调 MOMENT、随机森林和低标签 MOMENT-SVM。
- 输出 detection lead fraction、Recall、FNR、FPR、Precision、F2、PR-AUC 和每 seed FN/FP 数。
- 由至少两名了解业务的复核者盲法检查：全部电池 FN、各模型高置信 FP、多个模型共同错误；记录
  “标签疑似错误/曲线不完整/可能设备异常/无法判断”等预定义原因和一致率。

**判定。** 若没有业务复核，不写“识别真实电池故障”；若 99% Recall 的 FPR 仍不可接受，只报告
离线权衡，不使用“早期预警可部署”。

**状态：** 未完成；现有完整曲线安全复评已完成。  
**优先级：** P0（若安全章节保留为主要结果），否则 P1。  
**资源估计：** 中 + 业务人员时间。

### E08 推理效率与概率校准

**目的。** 把当前训练侧成本结论补全为部署侧证据。

**推理基准。** 同一 V100、相同数据读取边界，batch 1/32/256；100 次 warm-up 后至少 1,000 次
计时，报告端到端和纯模型 latency 的 median/P95、samples/s、峰值显存和模型文件大小。MOMENT-SVM
把 encoder 与 SVM 两段分别计时。CPU 基准可作为补充，不与 GPU 混报。

**校准。** 保存三类概率；只用 validation 拟合 temperature scaling，test 报 NLL、Brier、
15-bin ECE、可靠性图和选择性风险。电池 one-vs-rest 分数单独校准，检查 95%/99% Recall 阈值在
不同 seed 的漂移。

**判定。** 训练时间比值不能直接外推为推理时间比值。完成前正文只写“训练侧效果—资源权衡”。

**状态：** 未实现。  
**优先级：** P0/P1。  
**资源估计：** 低至中。

### E09 设备、时间或外部数据泛化

**核心假设 H09。** 低标签 MOMENT 的预训练先验在分布移动下比从头训练 TCN 更有价值。

**数据优先顺序。**

1. 同一来源的设备/充电器 ID：GroupShuffleSplit 或 GroupKFold，任何设备不得跨 split；
2. 时间戳：按时间先后训练/验证/测试，禁止随机回流；
3. 另一站点、设备批次或时间窗口：内部训练、外部锁定测试；
4. 若以上均不可得，构建按可观测条件（长度、幅值范围）分层的压力测试，但不得称为外部验证。

**比较对象。** 完整标签 TCN、完全微调 MOMENT、5%/10% TCN、5%/10% MOMENT-SVM、随机森林和
E03 最强基线。外部 test 上禁止重新调阈值；可单独报告“无适配”和“只用外部无标签数据适配”。

**主要指标。** Macro-F1、各类 Recall/F1、Battery PR-AUC/FPR、相对随机 split 的性能下降和
置信区间。

**判定。** 若 MOMENT 的性能下降更小，可将论文贡献加强为“分布移动下的低标签迁移”；若所有
模型明显下降，结论改为数据采集/站点特异性；若拿不到分组字段，明确列为未解决限制。

**状态：** 等待数据字段。  
**优先级：** P0（高质量期刊）/P1（一般内部毕业论文）。  
**资源估计：** 数据依赖，高不确定性。

## 4. P1：增强 MOMENT 论文深度的实验

### E10 参数高效微调

**假设。** LoRA 或更深的部分解冻能填补冻结 RBF-SVM（85.17%）与完全微调（95.37%）之间的
效果差距，同时显著减少可训练参数和显存。

**候选。** 解冻最后 8/12 层；LoRA 插入 attention 的 q/v 或 q/k/v/o，预注册 rank 4/8/16、
alpha 和 dropout 的小网格。先用 seed 42 validation 门控：Macro-F1 > 90%，可训练参数 < 全量
20%，峰值显存 < 全量 50% 时再扩展 seeds 43–46。门控 seed 不单独作为正式结论。

**输出。** Macro-F1、可训练/总参数、峰值显存、训练时间和每百分点提升成本的 Pareto 图。

**状态：** 未实现。  
**价值：** 若成功，可形成“标签—算力—效果三维选择”而不只是模型横向比较。

### E11 检索人工相关性评价

**假设。** 类别一致性低估或误判了充电曲线的业务相似性，MOMENT 可能在形态/故障机制相关性上
优于统计特征。

**设计。** 分层抽取至少 100 个 query；对 MOMENT、Statistical、Raw 的 Top-5 候选去重、随机
排序并隐藏方法名称；至少 2–3 名业务人员按 0/1/2 相关等级评价。报告 nDCG@5、平均相关等级、
bootstrap 区间和 Krippendorff's alpha/加权 kappa。样例在评价前确定，不能按结果挑选。

**判定。** 只有人工指标领先才能把检索从“类别代理”升级为“业务相似性”；否则保留当前有限结论。

**状态：** 未开始。  
**资源：** 低 GPU，高人工。

### E12 目标域自监督适配与插补

**假设。** 在不使用类别标签的条件下，以训练 split 的充电曲线进行掩码重构适配，可以改善
MOMENT 在目标域的插补和低标签分类。

**设计。** 只用训练 split 做 masked reconstruction；validation 选 epoch，test 最终评价。
比较 zero-shot MOMENT、只调 reconstruction head、LoRA encoder、自监督全量适配和线性插值。
同时评估适配后冻结表征的少标签分类，检查是否存在任务迁移收益或灾难性遗忘。

**边界。** 无论结果如何，都必须保留现有 zero-shot 负结果；新结果命名为“目标域自监督适配”，
不可改写为 zero-shot 优势。

**状态：** 未实现。  
**优先级：** P1/P2。

### E13 图表、表格和记录自动化

**最低输出。** 一条命令从正式 `metrics.json`/CSV 生成：

- 训练/验证 loss 与 Macro-F1 曲线；
- 原始和归一化混淆矩阵；
- 逐类别 Precision/Recall/F1；
- 多 seed 均值、标准差、配对差和箱线/雨云图；
- 参数量、训练时间、推理延迟、显存表；
- 300 DPI PNG、SVG/PDF 和投稿表格 CSV；
- 自动更新的实验索引与产物 SHA-256。

**状态：** 专项图已有，统一命令未完成。  
**优先级：** P1，但应在新增实验大规模开始前完成基础汇总，减少手工复制错误。

## 6. 结果出来后的论文定位决策

1. **E02 成立，且 E03 中 MOMENT 仍领先：**保留当前题目，以“预训练带来的低标签效率”为核心
   贡献；E09 若也成立，可加强为分布移动下的迁移优势。
2. **E02 成立，但 MiniROCKET/TS2Vec 相当或更好：**题目改为“基础模型与轻量时序表征的条件化
   比较”；MOMENT 是有竞争力的方法，不是唯一最优方法。
3. **E02 不成立：**不得把低标签收益归因于预训练；改写为“MOMENT-RBF 管线与 TCN 的经验比较”，
   或把论文主线转向统一协议和负结果分析。
4. **E09 显示随机划分结果大幅下降：**将论文定位为“随机划分会高估充电故障分类性能”的数据
   审计研究，优先报告分组泄漏/域偏移，而不是追求更高随机划分分数。
5. **E05/E07 发现大量标签疑似错误：**暂停模型排名结论，先清洗/复核标签，并从第一个正式 seed
   重新运行全部主表；不得只删除模型容易错的样本。
