# 当前实验证据总览（截至2026-10-19）

## 先说结论

原始统计旁路与增益头确实改善了冻结MOMENT分类管线。固定40%标签预算下，它在E03T中超过了预先列出的SVM/统计参照；补入可核对的历史同预算TCN后，**尚未证明MOMENT融合是综合最优方案**。

E03T的预定门槛通过与E05A的这一限制并不矛盾：前者只针对事先声明的7种方法，后者补上了遗漏的相关参照。不能只报道前者，也不能倒过来修改已经执行的门槛。

## 必须保留的负结果与边界

- E01低标签融合扩展门控失败；强统计基线削弱了仅对弱TCN/弱MOMENT的优势叙事。
- E01C强化统计对照的两预算整体门控失败；预训练相对随机有贡献，不等于所有预算下都超过统计方法。
- E03P的rank8/16 LoRA未超过强非适配参照；旧弱头上的LoRA增量不能证明新优化头下仍有净价值。E03D-v1数值失败及独立修订保留。
- E03E validation复制成功，E03T固定方法test确认成功；其范围均不是完整标签TCN排名或独立外部泛化。
- test此前在历史研究中已使用，当前结果也已查看；随机split跨seed重叠、validation反复复用。所有区间仅描述，不能当独立重复实验的总体置信保证。

## 下一步的合理边界

可以继续train/validation探索，但不能拿这份已消费的test反复追分，再把每次改进说成新的独立确认。更有价值的下一步是：

1. 获取脱敏设备/站点/会话时间元数据，冻结设备分组或时间外推协议；目前三个CSV字段不够，不能根据唯一sample ID臆测分组。
2. 保留TCN、强化统计方法和冻结MOMENT融合，预先固定比较与选择预算。若没有新数据，后续结论应明确是已知数据集上的探索性benchmark。
3. 同硬件单独比较推理/训练成本与工程需求，不能把头参数量当作MOMENT整条管线大小，或把V100和RTX计时混用。

E05A本身只审计保存预测，没有重训、重复test推理、再选阈值或改写E03T结果。之后的单独授权validation探索见上文；没有自动扩seed或再评价test。
