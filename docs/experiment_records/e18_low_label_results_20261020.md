# E18：统一下采样低标签基准（validation-only）

**状态：4 seed × 5 预算（1/5/10/20/40%）× 12 方法 = 240 条件 / 842,400 行；仅 validation，0 test。**

在 RTX 5090 新环境上重跑统一基准；同一 split、同一训练子集、同一 validation 行。固定超参，避免每个预算单独调参：

- HGB：`max_iter=400, lr=0.08, leaves=31, min_samples_leaf=20, l2=1.0`，F15/DYN 共用；
- MOMENT 原序列/ΔP/双流：logistic `C=1.0`；
- TCN：legacy masked，50 epoch，5 折 OOF + 全量子集，**无 validation 选模**；
- meta：logistic C 在 OOF 内 3 折选择；
- MultiRocket：interp_z 256、2000 features；MiniRocket：interp_z 256、10000 features；RidgeClassifierCV `{100,1000}` 训练内 3 折。

## 关键观察

- **1%–10%：MultiRocket 最强**。1% 92.52% 比 Full 89.15% 高 3.37pp，5% 95.73% 比 Full 93.85% 高 1.88pp，10% 96.16% 比 Full 95.13% 高 1.03pp；MiniRocket 明显弱于 MultiRocket。
- **20%：MultiRocket 与 Full 基本持平**（96.92 vs 96.90），TCN+DYN 96.76 也接近。
- **40%：Full 最高**（98.14%），TCN+DYN 98.09% 紧随，MultiRocket 97.25% 开始落后；TCN 97.62%。
- **TCN 的拐点在 10%–20%**：1% 61.91%（坍塌）、5% 84.67%、10% 89.17%，20% 跳到 95.63%，40% 97.62%。
- **MOMENT 单支在低标签弱**：原序列 1% 68.97%，ΔP 80.57%，双流 83.76%；但双流与 DYN 融合后 1% 89.12，接近 Full 89.15。
- **Full 的净收益集中在 20%–40%**：1%/5%/10% 均低于 MultiRocket；20% 与 MultiRocket 持平；40% 才领先约 0.9pp。
- 这与 E14/E16 的结论一致：低标签时简单强基线/经典卷积核更划算；融合/预训练价值在高预算和特定指标上更明显。

## 边界

- 这是新主机 RTX 5090 上的统一重跑，absolute 数值与旧 4080 结果有约 0.1–0.5pp 的硬件/库差异；不能把新旧数字混在同一列。
- HGB 固定超参、MOMENT 固定 C=1.0、TCN 固定 50 epoch；没有为每个预算单独调参，因此是“固定配置下的预算曲线”，不是各预算最优上限。
- MultiRocket/MiniRocket 使用 `interp_z` 256 点、固定 features；不支持 mask；不是其默认 50k 上限。
- 所有 seed 的 split 重叠，validation 反复使用；0 test；不是独立外部确认。
- 论文按既定范围可不引入 MultiRocket/MiniRocket；本表作为内部完整基准与适用边界证据保留。
