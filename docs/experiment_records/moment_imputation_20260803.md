# MOMENT 零样本缺失值插补实验（2026-08-03）

## 1. 实验目的

验证 MOMENT-1-large 在不使用标签、不更新参数的情况下，能否利用预训练重构头恢复充电功率
序列中的缺失区间。该实验用于补充分类结果，体现同一预训练模型的跨任务复用能力。

MOMENT 在预训练阶段通过随机遮挡 patch 并重构输入学习时序表示，因此缺失值插补与其预训练
目标直接一致。参考：

- [MOMENT 论文](https://arxiv.org/abs/2402.03885)
- [官方插补教程](https://github.com/moment-timeseries-foundation-model/moment/blob/main/tutorials/imputation.ipynb)

## 2. 数据与防泄漏协议

- 数据集继续使用统一过滤协议和 seed 42 划分清单。
- 只评价 7,020 条测试序列；类别标签不进入模型、遮挡生成或参数选择。
- 仅遮挡真实有效区间内的完整 MOMENT patch，不评价 padding 和不完整尾部 patch。
- 最少要求 3 个完整 patch，每条序列至少保留 1 个可见 patch。
- 输入保持原始功率尺度（`normalize: none`）。
- MOMENT 内部 RevIN 的均值和标准差仅由 `observation_mask × input_mask` 指定的可见点计算，
  被遮挡真值不参与归一化。
- 所有指标只在人工遮挡位置计算。

数据集 SHA-256 已核验为：
`5615a96a7894caed5d14463c77167af8098bdc1e1ebf32a33a89a12c3c5cf6e6`。

## 3. 遮挡条件

- 遮挡模式：
  - `random_patches`：随机选择不连续 patch；
  - `contiguous_block`：选择连续 patch 区间，模拟设备断连或连续缺测。
- 目标遮挡率：10%、25%、40%、60%。
- 遮挡随机种子：42、43、44、45、46。
- 同一样本和种子下，随机 patch 遮挡随遮挡率增加保持嵌套；连续遮挡围绕同一中心扩展。
- 每个条件保存遮挡 SHA-256，确保所有方法使用完全相同的缺失位置。

总计 `2 × 4 × 5 = 40` 个遮挡条件。

## 4. 对比方法与指标

| 方法 | 训练或参数更新 | 说明 |
|---|---:|---|
| MOMENT zero-shot | 无 | 使用预训练 reconstruction head |
| Mean | 无 | 使用可见点均值 |
| Forward Fill | 无 | 使用最近的历史可见值，前端缺失回填首个可见值 |
| Linear | 无 | 线性插值，边缘使用最近可见值 |
| PCHIP | 无 | 保形分段三次插值 |

主要指标为逐序列标准化后取平均的 Macro-NRMSE；同时报告原始功率尺度的 MAE、RMSE、
Macro-MAE、负值预测比例。五个遮挡种子按均值 ± 样本标准差统计。

| 缺失模式 | 遮挡率 | MAE | RMSE | Macro-MAE |
|---|---:|---:|---:|---:|
| 随机 patch | 10% | 9.75 | 20.40 | 9.43 |
| 随机 patch | 25% | 13.48 | 26.48 | 13.15 |
| 随机 patch | 40% | 19.22 | 33.99 | 18.82 |
| 随机 patch | 60% | 30.74 | 47.68 | 30.02 |
| 连续区块 | 10% | 33.22 | 51.83 | 28.97 |
| 连续区块 | 25% | 58.50 | 79.25 | 54.82 |
| 连续区块 | 40% | 72.63 | 95.49 | 69.10 |
| 连续区块 | 60% | 85.29 | 111.69 | 81.74 |

核心观察：

1. 线性插值在 8/8 个模式—遮挡率组合中获得最低 Macro-NRMSE，MOMENT 在 0/8 个组合中
   超过线性插值或前向填充。
2. MOMENT 始终明显优于可见值均值。相对 Mean 的 Macro-NRMSE 降幅在随机缺失下依次为
   78.4%、69.3%、57.7%、38.6%，在连续缺失下依次为 48.9%、18.9%、10.0%、4.1%。
3. MOMENT 的跨遮挡种子标准差很小，说明结论稳定，并非由某个有利遮挡位置造成；但稳定性
   不能替代绝对误差上的优势。
4. 连续缺失从 10% 增至 60% 时，MOMENT Macro-NRMSE 增长 2.82 倍，Linear 增长
   6.14 倍。MOMENT 的相对退化倍率较小，但其所有绝对误差仍更高，因此不能据此宣称
   MOMENT 更适合长缺口。

## 9. PCHIP 异常及报告边界

PCHIP 的 Macro-NRMSE 在随机缺失 10%–60% 下依次为 0.3608、1.5657、5.8472、22.9740，
在连续缺失下依次为 14.5415、487.9538、2,149.2652、14,895.9478。检查实现后确认，当前
PCHIP 对位于序列首尾的缺失点进行了无约束多项式外推；长边界缺口会产生极端预测，因此这些
数值不能解释为“PCHIP 方法本身普遍失效”。

为避免极端值压缩主图中其他曲线，PCHIP 保留在原始 CSV 中用于审计，但从主结果图和主要
结论中排除。若论文需要完整的强插值基线，可另行实现“PCHIP 仅在内部插值、边缘使用最近
可见值”的安全版本并重新运行；在此之前，不应使用当前 PCHIP 数值比较模型优劣。

## 10. 结论与论文定位

本实验是有效且适合写入毕业论文的**负结果/迁移边界实验**，但不适合作为 MOMENT 优势证据。
充电功率曲线具有很强的局部连续和平滑结构，线性插值的归纳偏置与这一数据特征高度匹配；
MOMENT 的通用预训练重构头在不做任何目标域适配时，没有转化为更低的插补误差。

这与少样本分类中冻结 MOMENT 表征的优势并不矛盾：分类实验使用预训练表示配合目标域
RBF-SVM，而本实验直接复用通用重构头；“表示可迁移”不等于“重构头也能零样本迁移”。论文
应将 MOMENT 的主要优势仍定位在低标签分类的标签效率，将本节放在扩展任务或局限性分析中，
用来说明预训练模型的跨任务收益具有任务和适配方式依赖性。

推荐正文表述：

> 在无需标签和参数更新的零样本缺失值插补实验中，MOMENT-1-large 在两类缺失模式和四种
> 缺失率下均优于可见值均值基线，但未超过线性插值和前向填充。其中线性插值在全部 8 个
> 条件中取得最低 Macro-NRMSE。该结果表明，MOMENT 冻结表征在低标签分类上的迁移优势并未
> 直接延伸到目标域零样本重构；对于局部平滑的充电功率序列，显式局部连续性先验仍更有效。

若后续希望提升 MOMENT 插补性能，可在训练集上进行目标域自监督遮挡适配、仅微调重构头或
加入 LoRA；但这些方案已经属于“目标域适配插补”，必须与本次 zero-shot 结果分开命名和比较。
