# 电池异常专用二分类实验

> 开始日期：2026-08-04  
> 当前状态：已完成（25 个正式源运行、60 个模型/比例/seed 结果）  
> 关键标签：原始标签 `2`（电池异常）  
> 协议版本：`battery_binary_protocol_version = 1`

## 1. 实验问题

已有实验把三分类模型输出转换为“电池异常 vs. 其余类别”，并在验证集调整报警阈值。完整标签
下 TCN 表现最好，但高召回仍伴随漏检和大量误报；极少标签下 MOMENT 的默认 Recall 更高，
但 PR-AUC 优势不稳定。此次实验检验：直接训练电池异常专用 one-vs-rest 模型，能否比“三分类
模型 + 后调阈值”得到更好的电池异常排序能力或 Recall–FPR 权衡。

## 2. 比较模型

1. 专用二分类 TCN：输出两类 logits，正类损失权重为 `1/2/4`；
2. 统计特征二分类基线：Logistic Regression 和 Random Forest，使用相同正类权重候选；
3. 冻结 MOMENT 表征 + 二分类 RBF-SVM：`C` 与正类权重在训练集内部五折交叉验证；
4. 已完成的三分类 TCN 和 MOMENT + RBF-SVM：作为严格对照，不重新训练。

比较 1%、5%、10% 和完整标签。数据划分、样本 ID、预处理方式和随机种子与已有实验保持
一致；TCN/统计基线使用原始尺度，MOMENT 使用单序列 z-score。

## 3. 防止测试泄漏

- TCN 与统计模型仅按 validation PR-AUC 选择正类权重；
- MOMENT-SVM 的 `C` 和正类权重仅由训练子集的五折 CV PR-AUC 选择；
- max-F2 以及 95%/98%/99% Recall 阈值仅在 validation 上确定；
- 所有模型和阈值确定后，才在 test 上评估一次；
- seed 42 只作为算力门控，不作为论文正式结论；是否扩展到五个种子只读取 validation 指标。

## 4. Seed 42 扩展门控（运行前预先规定）

分别在 TCN 和 MOMENT-SVM 模型族内，与相同 seed、相同标签比例的三分类模型比较。满足以下
任一条件才扩展该模型族到 seed 42–46：

1. 完整标签，或 1%/5%/10% 中至少两个比例的 validation PR-AUC 提高至少 1 个百分点；
2. 在 validation Recall 不低于 95% 时，完整标签或至少两个少样本比例的 FPR 降低至少
   2 个百分点。

若只出现更高默认 Recall、但 PR-AUC 与匹配 Recall 下的 FPR 均未改善，不认为专用二分类训练
有效。统计特征模型用于判断简单可解释特征是否已经足够；只有 validation 结果接近对应 TCN
或 MOMENT（PR-AUC 差距不超过 2 个百分点）时才扩展五种子。

门控阶段虽然程序会完整保存 test 结果以验证端到端流程，但作出“是否扩展”的决定时不访问或
使用 test 字段；门控结论会先写入本记录，再分析 test。

## 6. 论文使用边界

若五种子结果稳定改善，可作为“面向安全关键类别的任务特化”补充实验，并与通用三分类、
少样本表征迁移形成互补。若没有改善，同样适合写入论文：它能说明性能瓶颈主要来自表征与数据，
而不是把三分类简单改成二分类或增加类别权重即可解决。任何结果都不能被表述为已经满足实际
电池安全部署要求。

Logistic Regression 的 1% PR-AUC 为 83.24%，是该标签比例的最佳排序分数，但在 95% Recall
运行点仍有 73.10% FPR；从 5% 标签起，Random Forest 同时取得更高 PR-AUC 和更低 FPR。

专用 MOMENT 相对三分类 MOMENT 的配对结果为：

- PR-AUC 在 1%、5%、10%、100% 标签下分别变化 `+0.41`、`+1.69`、`+1.55`、`+2.08`
  个百分点；后三者的 95% t 区间分别为 `[0.23, 3.16]`、`[0.91, 2.19]`、
  `[1.44, 2.73]`，1% 的区间跨 0；
- 约 95% Recall 下，FPR 分别下降 4.37、7.67、6.89、3.27 个百分点；5% 与 10% 的区间
  分别为 `[−13.95, −1.39]` 和 `[−10.14, −3.64]`，1% 与完整标签的区间跨 0；
- 5%、10%、完整标签的 F2 分别提高 1.89、1.43、0.82 个百分点，区间均不跨 0；各比例
  Recall 差异的区间均跨 0。

因此，专用二分类目标确实改善了冻结 MOMENT 表征的电池异常适配，主要收益是保持近似 Recall
时减少误报，而不是进一步提高 Recall。但 41.61%–73.44% 的绝对 FPR 仍不可部署。

MOMENT-SVM 在 5%、10% 和完整标签的 15 个运行中全部选择正类权重 1；1% 标签时只在个别
seed 选择权重 4。因此上述提升主要来自将下游任务改为“电池 vs. 其余”并按 PR-AUC 选模，
而不是简单加大正类损失权重。

专用 MOMENT 相对三分类 MOMENT 的 FPR 低 4.65 个百分点，配对区间为 `[−8.44, −0.86]`，

### 9.4 少样本强基线改变了结论边界

在约 95% Recall 下，Random Forest 相对原少样本 TCN 的 FPR 在 1%、5%、10% 标签时分别低
30.15、38.87、38.67 个百分点；相对三分类 MOMENT 分别低 21.23、28.27、26.53 个百分点，
这些配对区间均不跨 0。其 PR-AUC 也在 1% 和 5% 标签下稳定超过两类深度模型，在 10% 标签
下稳定超过 MOMENT。

这意味着此前 MOMENT 相对少样本 TCN 的优势不能直接解释为“基础模型最适合电池检测”。更
准确的结论是：MOMENT 提高了通用三分类和表征迁移的标签效率，但针对电池异常这个单一目标，
少量可解释统计特征已经提供更有效的归纳偏置。

## 10. 统计特征重要性

Logistic Regression 使用标准化后的系数绝对值，Random Forest 使用 impurity importance；
两者均按每个模型归一化后跨五个 seed 汇总：

- `diff_std`（相邻功率差分的标准差）始终排名第一：Logistic Regression 的归一化占比从
  1% 标签的 35.84% 增至完整标签的 54.05%，Random Forest 从 17.65% 增至 26.52%；
- `max_abs_diff`（最大绝对突变）始终排名第二，占比约 9.88%–17.93%；
- Random Forest 的后续主要特征为 `q10`、`q25`、`std` 或 `slope`；
- `length` 只在 1% Random Forest 中排第五，完整标签时不在前五，因此当前结果不是单一长度
  捷径即可解释。

![电池二分类统计特征重要性](../figures/battery_binary_feature_importance_20260804.png)

这些结果表明电池异常标签与功率曲线的局部波动和突变幅度高度相关，具有业务可解释性；但
impurity importance 会受相关特征和取值分布影响，只描述模型关联，不能单独作为故障机理的
因果证据。

## 12. 最终回答

1. **专用二分类有帮助，但没有改变完整标签最优模型。**冻结 MOMENT 的 PR-AUC 和误报控制
   得到稳定改善，说明任务目标对齐有价值；完整标签 TCN 仍明显最好。
2. **MOMENT 的优势是可复用表征，不是电池检测绝对精度。**同一冻结特征可以服务三分类、
   二分类和检索，且不需要反向传播；但专用统计特征在电池二分类上更强、更快、更易解释。
3. **论文必须保留 Random Forest 强基线。**省略它会夸大 MOMENT 在少样本电池检测中的优势。
4. **当前仍不满足安全部署要求。**即使完整标签 Random Forest 在约 95% Recall 下平均仍有
   128.4 条漏检和 754.4 条误报；只有完整标签 TCN 将平均误报降到 40.6 条左右，但仍有约
   121.2 条漏检。接近零漏检的运行点会产生更多误报。
