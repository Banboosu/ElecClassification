# E01C 启动前协议：核带宽与随机表征归因对照

> 本文件只记录启动前设计，不回填实验结果。执行状态见 `todo2.md` 和运行状态 JSON。
> 机器可读协议：`configs/experiments/improvements/e01c_attribution_protocol.json`。

## 背景与边界

E01B 的 20%/40% 融合在四个验证划分上优于既有统计单分支，但还不能将全部增益归因于预训练。添加表征同时改变了核几何；`gamma='scale'` 也会随变换后的方差改变。随机架构产生的特征可能同样有帮助。

E01C 在已知 E01B 参照结果之后提出，仅为条件性的归因消融，不是对整体假设的盲法预注册，也不是独立外部数据验证。不修改 E01 的低标签门控失败结论，不改写 E01B 的数值或成功规则。

## 固定实验范围

- seed 43、44、45、46；不增加 seed 42。
- 训练标签比例 20%/40%；沿用父实验训练 ID、五折 CV 和 validation。
- 参照为已训练的 E01B“预训练 MOMENT + 全部统计”模型，复用其表征和结果，不重新调参。
- 两个新条件，每个 seed/预算都运行，共 **16 个新条件**：
  1. **匹配核带宽的统计分支**：仅原始 15 维统计，StandardScaler 和除以 sqrt(15) 与融合统计分支一致。
  2. **随机 MOMENT + 统计分支**：相同架构的 patch embedding 与 encoder 随机初始化、冻结、mask-aware mean pooling，使用相同 1,024+15 维 BranchScaler。

## 精确匹配带宽，而不是只匹配候选个数

每个 CV 训练折独立拟合**预训练参照**的 BranchScaler，按原 SVC 的 float64 输入计算实际 gamma='scale'，将该数值与 0.05、5.0 一起交给两个对照。

- C 固定为 0.1、1、10、100、1000，共 15 候选 × 5 折。
- 不从随机分支或统计分支自身的方差重新定义 scale gamma。
- 参照带宽只使用该 CV 训练折的选定样本，不能使用 CV held-out、外部 validation 或完整无标签训练池。
- 最终重拟合时，参照仅拟合完整的**选定训练子集**，不是全部 24,569 条训练池。
- 统计对照的最终 Pipeline 仅接受 15 维统计输入，使用保存好的数值 gamma，预测时不需要参照表征。

匹配统计控制在训练时借用参照表示估算一个不含标签的带宽标量，因此它是删除表征分支的诊断对照，不应描述为完全脱离基础模型训练过程的独立调参基线。

## 随机初始化控制

- 每个 data seed 对应一个随机模型初始化，同 seed 两个预算共用一次随机特征提取。
- 只将原配置的 `initialization` 改为 `random`，使用原 `build_model` 的直接构造路径；不调用 `from_pretrained` 后再覆盖标志。
- 提取期间阻止 `MOMENTPipeline.from_pretrained`、`T5Model.from_pretrained`、`T5EncoderModel.from_pretrained` 三个加载接口。
- 每个随机缓存记录加载防护、初始化 seed、提取源码和 manifest 哈希；不能拿预训练缓存冒充随机缓存。
- 新缓存仅含 train/validation，FP32，模型不训练。随机架构与预训练架构一致，预训练与随机分支都按原方法归一化和池化。
- 启动前真实合成输入冒烟核验参数量为 341,243,395、输出维数为 1,024、输出有限；抽查参数与公共预训练 checkpoint 不同。公共张量仅用于比较，不赋值给随机模型。

一次随机初始化/数据 seed 不能代表所有随机初始化的总体分布，结果解释须保留此限制。

## 启动前检查

受控后端先复现 seed 43、20% 的已有 E01B 参照：15 候选 × 5 折评分、最优参数、3,510 条 validation 预测、最终训练 scaler 都应一致。未通过则不启动新控制实验。

随后将协议、源码、依赖版本、配置、输入数据、参照模型与父实验指标/预测哈希冻结到独立 `frozen_protocol.json`。每个 seed 前再次检查，运行中不修改这些输入。

## 预设判定

分别评价两项主张，不将失败的一项藏在整体平均中：

1. **超出更强统计对照的实用增量**：每个预算中，预训练融合相对“原统计 RF、原统计 SVM、匹配带宽统计”三者的最强 validation 分数，平均提升至少 **1 pp**，至少 **3/4 seed** 严格提升；两个预算都达到才记该主张通过。
2. **预训练权重的额外贡献**：每个预算中，预训练融合比随机表征融合平均提高至少 **0.5 pp**，至少 **3/4 seed** 严格提升；两个预算都达到才记该主张通过。

第一项的统计参照合并了两个 SVM 搜索范围，且选择已有 validation 最强者，故比等候选个数的单一统计管线更保守，不宣称各方总搜索预算完全一致。

报告完整差值、方向和描述性区间。四个随机划分重叠；结果不是外部泛化证明，不使用“基础模型全面最优”的表述。

## 执行与停止

- 沿用已验证的 CUDA float64 距离矩阵和 CPU 5 进程 SVM 求解，不改变参数范围换速度。
- 16 个条件全部完成，不依据中途正负结果提前挑选、调权或改门槛。
- 成功/失败的两项结论都保存；最终仍为普通 RBF Pipeline，不依赖预计算核矩阵部署。
- test 不参与参数选择或评价；不生成 test 表征/预测。
- 本阶段结束只汇总归因控制，不自动开始 LoRA、全量微调或 test 评价。
