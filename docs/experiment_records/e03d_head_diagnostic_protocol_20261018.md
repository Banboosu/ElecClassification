# E03D 启动前协议：冻结缓存上的训练预算与输入尺度诊断

> 2026-10-18；只记录启动前设计，不回填结果。
> 机器协议：`configs/experiments/improvements/e03d_head_diagnostic_protocol.json`。
> 这是在已知 E03P 结果之后提出的条件诊断，不是独立确认，不改写原 LoRA 门控失败。

## 背景

E03P 的三个冻结头均在 30epoch 上限取得最好分数。统计 MLP 只有 75.49%，远低于匹配统计 SVM 的89.48%；LoRA 融合虽比同头冻结提高约5.13pp，却仍落后既有融合SVM约2.17pp。LoRA 后期训练损失下降而验证损失上升，不宜直接继续长训。

本轮只检查分类头，不重新训练或执行 Transformer，不提取适配后表示。复用已核验、未做标签适配的 AMP 缓存，并从原 CSV 一次性重建选定样本的原始统计。test 不生成特征、预测或指标。

## 两个因素，六次训练、十二个预算单元

沿用 seed43、40% 标签，9,827 train +3,510 validation。统计、MOMENT、融合三个支路，各运行两种模式：

1. **legacy_tail**：从 E03P 第30轮 last checkpoint 接着训练至200轮；模型、optimizer、GradScaler、CPU/CUDA/shuffle RNG 均继承，不重新初始化。30轮单元复用父状态并复核分数。
2. **fanin_gain**：从与父实验相同的共享头参数初值重新训练至200轮，仅改变一个固定全局输入增益；同时保留前30轮与200轮的最优模型及精确端点。

于是报告3支路×2模式×2预算共12个单元，但只增加6次廉价头训练。所有条件完整运行，不按中途正负结果追加LR、缩放方式或挑选预算。

## 不把长训练和重设 scheduler 混为一个因素

- 新鲜训练的第1–30轮严格沿用原30轮总步数的10% warmup+cosine；之后保持原终点LR **1e-4**，不把cosine重新拉长到200轮。
- legacy 模式直接继承前30轮，不回放、更换状态或重设优化器。
- 不早停，固定训练至200轮；报告预算内最好分和第30/200轮精确端点，避免只看更多验证查询带来的最好分。
- 其他设置与原头一致：head基准LR1e-3、weight decay0.01、batch128、验证batch64、AMP FP16、GradScaler初值1024、gradient clip1、交叉熵、hidden128/GELU/dropout0.1。
- 沿用受保护的 E03P 训练函数，在新进程内有界注入“固定30轮前缀+常数尾部”调度与预算快照钩子；退出作用域恢复，不编辑父代码。
- 每轮原子保存 last、best及RNG，保留30轮状态，支持中断恢复。

## 为什么检查输入增益

原头先把各支路除以维数平方根，使每个有效支路的总平方范数约为1；但第一层 Linear 的 fan-in 仍为1039，包括被置零的通道。由此其初始输入/激活可能偏小，尤其统计单支路只启用15维。对RBF有用的距离平衡不一定适合作为NN的默认幅度。

这只是待检验的优化解释，不据公式直接宣布发现了原因。

新增增益固定为：

`g = sqrt(1039 / 有效支路数)`

- 统计或仅 MOMENT：一个有效支路，g约32.23。
- 融合：两个有效支路，g约22.79。
- 整个拼接向量乘同一个g；保留原按样本LayerNorm、统计训练标准化、维数归一和相对支路权重，不额外引入列标准化或增益搜索。
- 模型头权重初值与父实验相同，增益是可保存的固定buffer，不训练。
- 在选定训练样本的前1024行做无标签激活幅度检查，不读取验证数据做探针，也不用探针挑选增益。

## 预设描述与候选规则

每个支路分别报告：

- legacy最好200−最好30至少 **1pp**，且端点200−端点30至少 **0.5pp**，才标记额外预算在本设置中有帮助。
- gain最好30−legacy最好30至少 **1pp**，才标记早期训练对该输入尺度敏感。
- 最优点位于预算最后10轮，标记边界尚未排除；不能称已经完全收敛。
- 同时展示train/validation CE与端点，不把更多轮次的选择机会误当独立泛化证据。

融合最好200若相对“父融合SVM、父匹配统计SVM、本轮全部统计/仅MOMENT最好200”的最高分至少 **+0.5pp**，且比同模式仅MOMENT至少 **+0.25pp**，才可列为建议复制的候选。即使满足也不自动复制，不恢复失败的E03P候选，不自动重跑LoRA或test。

## 实现与审计边界

- 冻结父输入、三组父checkpoint/历史/指标/标准化、AMP缓存、代码与依赖；拒绝带有非空adapter状态的父checkpoint。
- 数据准备只用选定训练样本拟合统计标准化，并须与父模型buffer来源一致；核对缓存哈希、样本ID、真值与划分。
- new head的gain=1须与父头完全等价；不修改E01/B/C/E03P受保护文件。
- legacy30的分数须复现父值；两个预算均核对历史最优、端点、模型哈希、预测/概率和指标。
- 原validation结果已被多轮查看；新200轮有更多选模机会。该单seed条件诊断不用于宣称普遍最优、唯一原因、LoRA有了新优势或外部泛化。
- 所有阶段完成只汇总，停止，不自动扩展。
