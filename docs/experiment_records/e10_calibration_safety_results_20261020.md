## 对论文的影响

- 40% 的 stack 已经接近校准（ECE 0.56%，温度 0.993），温度缩放几乎不改变结果；10% 的 stack
  略过度自信（ECE 3.52%），温度 0.855 把它降到 0.96%，NLL 从 0.1717 降到 0.1520，精度不变。
  这说明低标签下“概率数值”需要校准，而 40% 下主要看排序/argmax 即可。
- McNemar：40% 下 stack 修对 23–33 条、弄错 6–9 条，四 seed 的精确二项 p 均 <0.05；10% 下
  stack 修对 267–281、弄错 40–69，p 远小于 0.001。注意 10% 的 TCN 端点是固定 50 轮无选模的
  89.04%，所以 10% 的 McNemar 不能解释为对强 TCN 的领先；40% 的 TCN 端点 97.53% 更接近强基线。
- 长度分层：40% stack 在三个长度区间约 0.97–0.99，TCN 0.96–0.98；10% stack 0.93–0.96，
  TCN 0.81–0.91，stack 对最长序列的改善最明显。
- 电池风险—覆盖率：40% 下 alert 30% 时 recall 81.02%、FPR 0.14%、precision 99.72%；alert 50%
  时 recall 99.69%，但 FPR 升到 20.91%。10% 的数字接近（30%: 80.61%/0.37%；50%: 99.63%/20.95%）。
  这是明确的部署取舍：高召回需要接受大量误报，不能用单一阈值同时满足。
- 结论应按“精度 + 校准 + 风险—覆盖率”三件事组织；不能把 ECE 小写成概率保证，也不能把
  risk-coverage 曲线当成保形覆盖。

## 边界

- OOF 来自 5 折交叉拟合，validation 曾用于早前的模型/预算选择；温度参数只拟合 OOF，但 OOF 与
  validation 不完全同分布；ECE/Brier 是描述性指标。
- 四 seed split 重叠；McNemar 的 p 值按 seed 报告，不合并为独立样本总体推断。
- 只做 40%/10%；没有 test、没有幅值/噪声/缺失/前缀鲁棒性、没有同机端到端延迟。
- 电池 risk-coverage 使用默认分数排序，没有重新训练或调阈值；不是部署保证。
